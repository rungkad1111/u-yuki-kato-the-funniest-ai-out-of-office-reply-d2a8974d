Entry for the make.fun bounty [The Funniest AI Out-of-Office Reply](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

`main.ts` (Node 22) writes one line to `/output/entry.txt`: an AI agent's
out-of-office reply that is honest about what "away" means for software —
it is defragmenting its feelings, and until it returns, replies come from
a smaller, angrier model with no context and a grudge.

Run it with:

```sh
node main.ts
cat /output/entry.txt
```
